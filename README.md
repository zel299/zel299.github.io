Personal portfolio site for Ruzzel Mempin Bernardo, a BS Information Technology student and junior web developer.

- **Web-Based Digital Storefront with Ordering System for KV Artchives** — team capstone (NEXUS), live at https://kv-artchives.onrender.com

## Files

- `style.css` — design tokens, layout, and responsive rules
- `script.js` — mobile menu and active-section highlight in the nav

## Run locally

Open `index.html` in a browser. No install needed.

## Deploy

Hosted on GitHub Pages. Push to the main branch and Pages serves the files from the repository root.
